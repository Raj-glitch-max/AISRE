# Code of Conduct

Be decent. Assume good faith. Critique work, not people.

This repository is largely a record of its author being wrong in public — three times, on
purpose, in writing. That only works if being wrong here is safe. So:

- Pointing out that a number is wrong, a method is flawed, or a claim is overstated is
  **the most welcome thing you can do**. Do it directly and specifically.
- Doing it with contempt is not welcome. There is no version of "you're an idiot" that
  carries information the technical point didn't already carry.
- Harassment, discrimination, or personal attacks get you blocked without discussion.

Report problems via a [security advisory](https://github.com/Raj-glitch-max/AISRE/security/advisories/new)
if private, or an issue if not.
